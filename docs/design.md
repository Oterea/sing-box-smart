# 已确定的第一版设计

- 分数越低越好；真实延迟和综合分数分别保存。
- 成功：`L=.8L+.2*delay`；失败不改 `L`。
- 每次结果：`S=.95S+success`、`N=.95N+1`、`f=.9f+.1*failure`。
- `p=(S+1)/(N+2)`；`score=L/(p^3*(1-f)^3)`。
- 未有成功延迟时面板显示“—”，不伪造高延迟。
- 当前分数大于最好候选分数的 1.4 倍时，先确认候选再切换。
- 检查分层：当前节点 2 秒；动态优秀候选 30 秒；普通节点 5 分钟并错峰。分层按分数分布中最明显的断层动态生成，不固定前 10。
- 普通节点出现失败后成功或相对近期延迟基线明显下降时，安排 3、6、12、20 秒恢复复查；结果使用同一评分公式，复查不直接加分。
- 不保存评分状态跨重启；保留运行日志用于以后调整参数。
- 当前机场全部失败时保留现有选择，每 3 秒重试；启动全部失败时暂不选择，出现可用节点后再选择。
