# 当前实现与已知边界

本文件描述当前源码行为；未实现的保证和已知差异单独列出。

## 评分

- 首次成功时 `L=delay`；随后成功时 `L=.8L+.2*delay`；失败不更新 `L`。
- 每次有效节点结果：`S=.95S+success`、`N=.95N+1`、`f=.9f+.1*failure`。
- `p=(S+1)/(N+2)`，`score=L/(p³*(1-f)³)`，越低越好。
- 未有成功延迟时无分数，显示“—”；数值溢出显示“∞”，比较仍使用未截断值。
- 每次有效节点结果增加检查次数并保存历史，接口错误不计次数和分数。

## 启动与选择

启动只探测当前组，每节点最多一项在途探测。达到 10 秒且所有节点完成过一次后结束启动阶段；并不等待所有再次发起的在途探测结束。首次自动目标是最新一次成功且有分数的最低分节点，确认探测也照常计分，再次比较后写入 selector 并回读。

当前分数超过最佳可用其他节点的 1.4 倍时提出自动切换；比较遍历全组，不强制只选候选层。无当前节点或当前无分数时也可提出目标。当前最近一次失败本身不会强制切换，仍看分数。手动选择只要求确认成功，不受分差门槛限制。

全组最新结果都失败时保留已有选择，进入不可用阶段，将节点重新安排为 3 秒后重试；出现成功结果后恢复正常计划。启动全失败时不选节点。

## 分层与间隔

按当前最新结果成功、有有限分数的节点排序。最大相邻相对差至少 25%、至少第二大差的 2 倍、至少移除最大差后中位差的 2.5 倍，才认定明显断层。

断层之前的节点成为候选。没有断层且有效节点超过 20 时，候选数取 `max(10, floor(有效数/4))`，所有情况下最多 20 个。之前的层级字段不参与留层缓冲；没有额外连续两次确认或滞回。当前节点另标当前层，仍参与上述排序，因此其他候选可能只有 19 个。

正常间隔配置为当前 3 秒、候选 30 秒、普通 5 分钟；单节点通常从结果完成时计算下次到期。全组重新排期时按各层节点数错峰，第一项可能立即到期。每次确认切换后的全组重排也会清除恢复计划。

## 恢复信号与计划

只有非启动阶段、探测前为普通节点、非当前节点、normal 原因的结果才检测恢复迹象。

1. 上一次失败，这次成功且延迟 ≤400ms。
2. 从历史中取最多最近 5 次成功延迟，至少 2 次；排序后取中间元素（偶数样本取偏大的中间项）。本次成功至少下降 100ms，且不超过基线的 75%。这项没有 400ms 绝对上限，失败后高延迟成功若仍明显下降也可触发。
3. 若前两项未触发，计分后仍是普通节点，且分数不超过候选边界的 1.15 倍，也可启动复查。此项当前没有显式检查本次成功。

恢复计划配置 3、6、12、20 秒，各次间隔从前次完成算起；恢复步骤未到期前不会走普通探测，到期后才进行 recovery 探测。成功推进步骤，失败或最后步骤完成后结束。结束时按当时层级安排 30 秒或 5 分钟；晋升候选不会立即结束已有恢复步骤，成为当前或全组重排则可能清除步骤。全部结果正常计分。

## API、配置与服务

真实探测是调用 Clash API 的 `/proxies/{node}/delay`，URL 默认 HTTPS generate_204；不是 ICMP ping，也不是复用 TCP 流的探活。探测超时默认 4 秒，给 sing-box 的内部 timeout 通常少 500ms。HTTP 错误响应、解析失败或 delay≤0 作为节点失败；外层截止时间超时也作为节点超时，其他传输错误作为 API 异常。401/404/500 等不会被额外健康检查重新分类。

API 异常时停止新探测和切换，每 3 秒尝试健康检查根策略组。不会自动重新发现订阅或策略组变化；发现发生在程序启动、配置应用时。`-pins` 仍是必填兼容参数；目录读取成功时优先动态发现。

暂停取消探测上下文并增加 generation，旧结果丢弃；不能撤回已经发出的切换请求。恢复检测安排全组到期，没有等待全组刷新完才允许选择的门槛。

评分不跨重启保存。连接 JSON 保存 API、root、pattern，并优先覆盖启动参数；面板通过一个完整配置接口验证并应用三者，避免分步保存造成半应用状态。检测间隔、URL、恢复阈值没有监控面板编辑入口。

## 面板与日志

后端历史 24 条，显示最近 20 条；不足不补假样本。分数满高 2000，延迟满高 1000ms，超出封顶；SVG 高度映射到 40px 内容区。延迟颜色 ≤200 绿、≤400 黄、其余红；分数颜色相对全组最佳分数的 1.4/2.5 倍划分。失败用灰柱，不伪造延迟。

历史队列通过内容重叠识别新样本，每帧 300ms；没有重叠时直接形成一帧，不保证逐次重放。当前动画是替换 SVG 后整体短距离移动、新柱同时长高，不是严格先左移一格再长高。网络中断超过后端保留历史长度时无法还原丢失的每次探测。

SSE 首次完整、后续节点差量，全局信息仍全量。所有连接共享一个每 250ms 采样的快照源；慢连接可跳过中间版本，只保留最新状态。事件带 `revision` ID，并发送 15 秒注释心跳，但没有持久重放；跨组删除、重启 ETag 身份问题见接口文档。

日志为滚动文本（文件名 `events.jsonl`），不是 JSONL；队列容量 256，正常由后台写文件，但队列满时 Write 会阻塞。运行记录内存最多 100 条，面板显示最近 8 条。
