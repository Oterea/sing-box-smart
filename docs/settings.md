# 面板设置

## 在哪里修改

- **9797 → 运行设置**：检测频率、探测地址与超时、立即检查次数、自动睡眠、日志级别、延迟颜色和高级判断参数。保存后立即生效，不重启服务。
- **LuCI → sing-box-smart → 核心配置**：当 smart 核心未启动、无法打开 9797 时，仍可修改 API 地址、根策略组、匹配规则、监听地址、gRPC 和日志目录，并保存后重启 smart。这里不编辑运行参数 JSON，运行参数统一在 9797 中修改。
- API 地址、根策略组和匹配正则在 9797 正常时也可以从连接设置修改；LuCI 核心配置是故障恢复入口。

LuCI 的“检查 sing-box”按钮调用独立的 `config-settings check` 命令，不依赖 smart 面板进程；它会直接检查 API、根策略组和策略组发现结果。检查失败时仍可先保存本地配置，修正 sing-box 后再重启 smart。

设置区域默认收起，展开后每项参数直接显示简短说明，不再额外折叠。保存失败会显示原因，保留原设置。更改显示或日志级别不会重排探测。切换正在进行时需稍后保存运行设置。

“默认显示节点数”控制实时节点表现表格；“每组长期表现显示数”控制长期表现中每个稳定性分组默认显示的节点数。两者只影响面板显示，节点仍会继续检测并参与选择；每组超过上限时可单独展开全部节点。

## 检测与高级参数

| 设置 | 默认值 | 含义 |
| --- | --- | --- |
| 当前 / 候选 / 普通节点间隔 | 3 秒 / 30 秒 / 300 秒 | 正常阶段的分层探测频率 |
| 后台策略组检查间隔 | 30 分钟 | 正常运行时，未选中的机场策略组中每个节点的检查间隔；节点会在整个间隔内均匀分散 |
| 睡眠低频检查间隔 | 60 分钟 | 自动睡眠后所有机场策略组统一使用的低频检查间隔；唤醒后当前策略组恢复正常频率，后台策略组恢复后台间隔 |
| 探测超时 | 4 秒 | 单次检查等待上限 |
| 启动 / 恢复观察 | 10 秒 / 5 秒 | 观察期间连续探测，暂不自动选择 |
| 故障重试间隔 | 3 秒 | 节点全部不可用或管理接口异常时重试 |
| 切换分数比例 | 1.5 | 比较当前节点与候选节点分数 |
| 恢复延迟比例 / 最少下降 / 良好上限 | 0.75 / 100ms / 400ms | 恢复迹象判断条件 |
| 恢复复查间隔 | 3,6,12,20 秒 | 复查逐步放慢的间隔序列 |
| 历史样本数量 | 24 | 每节点内存保留数量，图表最多显示 20 条 |

修改探测地址或超时会取消旧探测，旧结果不会继续计分；已收集的分数与历史保留。减少历史数量会立即裁剪旧样本。改变正在进行的观察时长会重新开始该观察窗口。切换分数比例只影响后续判断，不直接修改分数。

## 睡眠

- 默认关闭，先在 LuCI 配置可用的 sing-box gRPC 地址，再在 9797 启用。
- 默认在 10 分钟窗口内有效流量低于 64 KiB 时睡眠。
- 默认单个连接 5 秒内累计达到 1 MiB 时唤醒，不合并不同连接。
- 探测流量和 smart 面板管理流量被排除。
- 睡眠时修改阈值不会主动唤醒；关闭自动睡眠会恢复检测。
- 面板以分钟、KiB、MiB 展示，API 中时长使用秒，流量使用字节。

已有配置中的旧阈值会保留；在面板设置为 1 MiB 并保存后，后续升级无需再次手工编辑 conf。

## 日志与延迟颜色

默认日志级别为 INFO，改级别后立即影响新日志。DEBUG 额外记录探测细节；日志轮转仍保留当前文件与一个 5 MiB 旧文件。

延迟颜色默认：≤300ms 绿色，300–600ms 黄色，>600ms 红色。两个分界值均可修改，且绿色上限必须小于黄色上限。数字、历史柱和图例同步更新。只改变显示，不影响评分、候选分层或恢复判断。

## 窗口适配

9797 的字号、卡片内边距、按钮、表格行高和列宽通过 CSS `clamp()` 随窗口宽度在上下限内连续调整。小屏设置切为单列，节点表格保留横向滚动，不压缩到无法阅读。手机输入框保留至少 16px 字号。所有尺寸规则集中在 `web/responsive.css`，不使用 JavaScript 轮询窗口尺寸或整页缩放。

## 保存、升级与优先级

OpenWrt 中的文件：

- `/etc/sing-box-smart/connection.json`：API、根策略组、匹配正则。
- `/etc/sing-box-smart/runtime.json`：9797 运行设置。
- `/etc/sing-box-smart/service.json`：LuCI 核心启动设置，包括监听、gRPC 和日志目录。

新文件以临时文件写入、同步后原子替换，权限为 0600。设置目录已在系统升级保留列表中，软件包更新也不会覆盖这些用户生成文件。其他平台的运行设置位于 `-settings` 文件所在目录的 `runtime.json`，服务设置为同目录 `service.json`。

## 模块边界

- `internal/preferences`：运行设置数据、范围校验与存储。
- `internal/config/preferences.go`：API 数值与内部时长的转换。
- `internal/app/preferences.go`：事件循环内应用设置，调整探测、睡眠和日志。
- `internal/app/activity_source.go`：gRPC 活动源生命周期。
- `internal/httpapi/preferences.go`：设置读写接口，不实现探测逻辑。
- `web/settings.js`：表单与收起说明；不负责评分或调度。
- `internal/background`：后台机场策略组的独立状态、均匀调度和结果归档；不参与当前策略组选择。
- `internal/app/runtime.go`：串联当前策略组和后台策略组的调度；两者共用探测器、状态模型和长期稳定性记录器。
- `web/app.js` 与 `web/node-detail.js`：节点表现卡片通过同一套节点表格、详情和历史渲染逻辑切换机场策略组；切换展示组不会调用 sing-box 切换 API。
- `internal/serviceconfig`：LuCI 服务设置校验和安全保存，不执行输入中的 shell 内容。

LuCI 仅能调用固定的读取与应用命令，并写入固定暂存文件，未开放任意配置文件写入或任意命令执行。
