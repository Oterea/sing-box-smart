# 运行日志

sing-box-smart 使用统一的 JSON Lines 日志。日志文件默认是 `logs/events.jsonl`，每行一个完整事件；生产部署中通常由 `LOG_DIR` 或 `-log-dir` 指定目录。

每条记录固定包含时间、级别、模块、事件名和消息；可选的 `fields` 保留数字、布尔值、数组、对象和 `null` 等原始 JSON 类型。这样探测、切换、API、gRPC 活动、睡眠和配置事件可以共用同一个记录入口，睡眠只是其中一个模块。

```json
{"time":"2026-10-11T10:00:00Z","level":"INFO","module":"sleep","event":"entered","message":"检测到长时间无用户活动，自动暂停节点检测","fields":{"idle_seconds":600}}
```

日志级别通过 `-log-level` 设置，默认是 `info`：

- `debug`：包含详细探测和诊断记录。
- `info`：记录正常运行的重要状态变化。
- `warn`：记录可恢复异常。
- `error`：记录无法完成的操作。

日志文件采用有界轮转，保留当前文件和一个轮转文件，避免长期运行无限增长。面板中的最近事件仍使用独立的内存列表，不会把完整日志全部传到浏览器。
